# Оценка риска ДТП по выбранному маршруту

**Задача.** Сервис аренды автомобилей хочет оценивать риск ДТП по выбранному маршруту и предупреждать водителя. Нужно проверить, реализуема ли такая система на имеющихся данных.

**Что сделано.** Загрузка данных из удалённой базы (SQLAlchemy), первичное исследование, анализ факторов ДТП, корреляции PHIK, обучение LightGBM и XGBoost, подбор гиперпараметров (Optuna), анализ модели (SHAP, permutation importance), выводы о недостающих данных.

**Стек.** Python, pandas, scikit-learn, LightGBM, XGBoost, Optuna, SHAP, SQLAlchemy

**Результат.** accuracy лучшей модели ~0,72; сформулированы требования к данным
